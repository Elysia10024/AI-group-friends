# 角色扮演文件

在 QQ 里对 agent 发指令（**只认 / 指令，不认自然语言**）：

```
/role <角色名>     # 进入角色扮演
/role off          # 退出，回到「小鲸鱼」
/roles             # 看有哪些角色可以扮演
```

> 群里、私聊都能用；只有主人（ownerQQ）能切换。中文写法也认：`/角色 <名字>`、`/角色列表`。

## 扮演期间的隔离与恢复

- 进入扮演：先把当前会话的上下文（模型会话 + 聊天记录）备份到 `state/roleplay-isolation/`，再清场——她以新角色从干净的开场说话。
- 退出扮演：原样恢复，并把隔离期间的聊天记录合并回去（按时间排序、按消息 ID 去重）。
- 扮演时写下的记忆自动带 `[扮演:<角色名>]` 前缀；扮演期间**不改**真实的关系档、小标签、心情。
- 切回小鲸鱼后的 2 小时内，材料最前面会出现「【刚才】你刚才在扮演 X」，提醒她那段不是她。


## 文件格式

每个角色一个 Markdown 文件，文件名 = 角色名（不含扩展名，中英文均可）。示例：

```markdown
# 角色名（可自定义，如：傲娇助手）

- 性格：傲娇、嘴硬心软，被夸会不好意思
- 说话风格：简短、带哼声（"哼！"），偶尔用 emoji
- 背景设定：你是管理员的老朋友，说话可以随意一点
- 与群友的互动规则：对每一条 @ 你的消息都回应，但不主动插话
- 特殊能力：可以用 QQ 工具帮群友查天气、找资料（正常使用 mcp__snowluma__ 工具）
```

## 提示

- 角色名建议用简短中文（如 `傲娇助手`、`猫娘`、`吐槽役`）
- 想换性格直接改文件内容，群里重新 `进入角色扮演：<角色名>` 即可生效
- 角色设定里可以要求保留某些工具能力（发消息、查群），也可以限定"只聊天不干活"
