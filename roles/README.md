# 角色与人格

AI 群友的**性格、说话方式、对谁怎么说话**，全部写在 `roles/` 目录里。

**你完全可以换成自己想要的性格，也可以加任意多个角色。**

---

## 一、两种切换方式

### 方式 1：在群里直接说（最简单）

```
进入角色扮演：傲娇助手
```

她就按 `roles/傲娇助手.md` 里的设定说话。想恢复默认：

```
退出角色扮演
```

### 方式 2：改状态文件

`state/current-role.json` 记录当前角色，改完重启桥接生效（控制台 `http://127.0.0.1:3100` 里也能切）。

---

## 二、两种文件格式（都支持）

### 格式 A：单文件式（简单，适合快速试）

```
roles/
└── 傲娇助手.md
```

一个 Markdown 文件就是一个角色，文件名 = 角色名。

### 格式 B：目录式（推荐，功能完整）

```
roles/
└── 小鲸鱼/
    ├── core.md            ← 人格核心（每轮都注入，最重要）
    ├── 速记.core.md        ← 浓缩版人设 + 流程硬规则
    ├── groups/
    │   ├── example.md     ← 群设定模板（复制成 <群号>.md 用）
    │   └── 123456789.md   ← 某个群的专门设定
    └── private/
        └── 987654321.md   ← 某个人的私聊专门设定
```

目录式的优势：

- **人格可以很长**（小鲸鱼的 `core.md` 有 30 KB）
- **可以按群/按人定制**：她在 A 群和 B 群可以是不一样的性格
- **有速记层**：`速记.core.md` 是每轮都注入的浓缩版，防止长人格被上游压缩时丢细节

---

## 三、怎么加一个新角色

### 最快：单文件

1. 在 `roles/` 下新建 `猫娘.md`
2. 写内容：

```markdown
# 猫娘

- 性格：黏人、爱撒娇，句尾常带"喵"
- 说话风格：短句，偶尔用颜文字
- 背景设定：你是群里的团宠
- 互动规则：被叫名字一定要应，但也别每条都抢话
```

3. 群里说 `进入角色扮演：猫娘`

### 完整：目录式

1. 建目录 `roles/猫娘/`
2. 写 `core.md`（人格，可以写很长）
3. 可选写 `速记.core.md`（浓缩版 + 硬规则）
4. 可选建 `groups/`、`private/` 放场景设定

## 四、人格里该写什么

参考 `roles/傲娇助手.md` 的结构：

```markdown
- 性格：……
- 说话风格：……
- 背景设定：……
- 与群友的互动规则：……
- 特殊能力：……（要不要用聊天工具、能不能主动发言）
```

**几个经验**：

- **越具体越好**。"性格活泼"没用，"爱用反问句、被夸会岔开话题"才有用
- **说清楚边界**。比如"只在被 @ 或叫名字时回复，不主动插话"
- **可以限制工具**。写"只聊天不干活"，她就真的不会去调工具
- **长人格记得写速记**。上下文被压缩时，`速记.core.md` 是最后保住人设的东西

## 五、仓库里现成的角色

| 角色 | 文件 | 说明 |
|---|---|---|
| 小鲸鱼 | `roles/小鲸鱼/core.md`（30 KB） | 完整人格，含大量对话习惯与边界。**这是最完整的参考范例** |
| 傲娇助手 | `roles/傲娇助手.md` | 单文件式的最小示例，适合当模板 |
| 群设定模板 | `roles/小鲸鱼/groups/example.md` | 复制成 `<群号>.md` 使用 |

> 仓库里的群/私聊设定只有模板（`example.md`）——真实的群号、QQ 号属于个人隐私，没有公开。

## 六、改完怎么生效

| 改动 | 生效方式 |
|---|---|
| `roles/*.md` 内容 | 群里重新 `进入角色扮演：<名字>`，或重启桥接 |
| 新建角色 | 直接说 `进入角色扮演：<新名字>` |
| 群/私聊设定 | 重启桥接 |
| `state/current-role.json` | 重启桥接 |
