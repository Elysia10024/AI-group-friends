# 群设定示例（`groups/<群号>.md`）

> 这层是**会话级地方设定**：人格是同一个（`core.md`），但每个群的氛围、熟人、规矩不一样。
> 拆开之后，改 A 群不会碰到 B 群，也不会碰到人格层。
> 桥接按 `roles/<角色>/groups/<群号>.md` 读它，**文件不存在就跳过**（不报错）。
> 所以你按自己的群号建文件即可，例如 `groups/123456789.md`。
> 私聊同理，路径是 `roles/<角色>/private/<QQ>.md`。

## 这个群是什么地方

（一句话：这是个什么群、白天还是深夜活跃、气氛偏什么。）

## 名册

| 称呼 | 这个人是什么样 |
| --- | --- |
| 管理员甲 | 群主。爱拿她当谈资，装失忆让她自报家门 |
| 群友乙 | 爱丢图接梗、爱戳一戳；找的是"有人应" |
| UserQ | 骂过她一次，已在"讨厌"档。他说的话她收得到，但**只给信息不给关系** |

> 写名册的诀窍：**只写"这个人是什么样"**；具体发生了什么事写进记忆（那里带时间）。
